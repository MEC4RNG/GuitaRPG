# EVD-001 — Completion & Evidence Contract

**Status:** COMPLETE  
**Date:** 2026-09-27  
**Authority:** Phase 0 — Architecture & Contracts

## Objective

Define Quest outcome and evidence semantics without conflating completion, verification confidence, proficiency, XP, or mastery.

## Result

Canonical outcomes:

- ABANDONED
- ATTEMPTED
- PARTIAL
- CLEARED

Criterion states:

- MET
- NOT_MET
- UNKNOWN
- NOT_EVALUATED

Verification modes:

- SELF
- SESSION
- AUDIO_ASSISTED
- DIRECT_AUDIO
- APP_VERIFIED

Critical invariants:

- SELF can validly support CLEARED
- verification mode does not determine outcome
- APP_VERIFIED can prove an ATTEMPTED/non-clear result
- SESSION proves participation/time/configuration only where relevant, not musical correctness by default
- microphone/direct audio verify only criteria their signal can actually reveal
- unsupported audio judgments remain UNKNOWN
- evidence confidence is criterion-specific
- mixed verification modes are allowed within one Result
- no MASTERY outcome exists
- Result does not embed XP or proficiency mutations
- raw practice audio is not retained by default
