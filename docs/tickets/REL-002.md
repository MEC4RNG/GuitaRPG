## Resumed application blocker

A real Playwright execution against the disposable local Supabase stack could not
reach Generate. Supabase anonymous Auth succeeded and created the Player bootstrap,
but `OnboardingFlow.finish()` failed at the production
`player_tuning_preferences.upsert(...)` call with:

`permission denied for table player_tuning_preferences`

The PLY-002 migration grants INSERT on `(player_id, tuning_context_id, rank,
is_default)` and UPDATE only on `(rank, is_default)`. The PostgREST upsert uses the
`player_id,tuning_context_id` conflict target and requires compatible UPDATE authority
for its generated conflict-update path. Consequently a new authenticated/anonymous
Player cannot complete the accepted onboarding path and cannot reach the required
Generate → Session → Complete → History browser loop without bypassing onboarding.

This is not an REL testability adjustment. Repair requires a forward-only
ONB-001/PLY-002 persistence remediation; the applied PLY-002 migration must not be
edited. REL-002 is therefore terminal **BLOCKED**. No browser test is labeled E2E, and
P2-GATE-001 remains unauthorized.
