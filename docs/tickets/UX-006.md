## UX-006-R1 — Fresh-Preview Player bootstrap

The initial Preview review found that a fresh browser could open Generate before it had a Player
identity. Generate then described the missing identity as a Quest-generation failure. The remediation
keeps identity ownership in the existing anonymous onboarding flow:

- Generate resolves the current Player before enabling generation.
- Missing identity routes to `/onboarding?next=/generate` without attempting generation.
- Unexpected identity lookup failures use truthful Player-session copy.
- Onboarding validates an internal relative return path, rejects absolute and protocol-relative
  destinations, and defaults invalid input to Home.
- Completed onboarding retains account-protection/recovery content and exposes `Continue to
  Generate` for this entry path.
- Existing authenticated Players restore their Player-scoped draft and remain on Generate.
- Protected UX CI exercises the fresh entry on desktop Chromium, Pixel 7 Chromium, and mobile
  WebKit, including axe checks and horizontal-overflow assertions.

No migration, Auth configuration change, staging mutation, production change, or public-traffic
change is part of UX-006-R1. PR #6 remains draft/open/unmerged pending refreshed Preview review.
