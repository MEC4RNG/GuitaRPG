## UX-006-R1 — Fresh-Preview Player bootstrap

The initial Preview review found that a fresh browser could open Generate before it had a Player
identity. Generate then described the missing identity as a Quest-generation failure. The remediation
keeps identity ownership in the existing anonymous onboarding flow:

- Generate resolves the current Player before enabling generation.
- Missing identity, including Supabase's expected `AuthSessionMissingError`, routes to
  `/onboarding?next=/generate` without attempting generation.
- Unexpected identity lookup failures use truthful Player-session copy.
- Onboarding validates an internal relative return path, rejects absolute and protocol-relative
  destinations, and defaults invalid input to Home.
- Completed onboarding retains account-protection/recovery content and exposes `Continue to
  Generate` for this entry path.
- Existing authenticated Players restore their Player-scoped draft and remain on Generate.
- Protected UX CI exercises the fresh entry on desktop Chromium, Pixel 7 Chromium, and mobile
  WebKit, including axe checks and horizontal-overflow assertions.

No migration, Auth configuration change, staging mutation, production change, or public-traffic
change is part of UX-006-R1. PR #6 remains draft/open/unmerged pending refreshed Preview review.

## UX-006-R2 — MEC visual clarity and layout refinements

The visual-review remediation keeps the existing Quest, Journey, and Session contracts while
reducing repeated presentation:

- Generate exposes only `Save Quest` and `Start Quest`; Practice remains a Journey action.
- Map uses a keyboard-operable ARIA tab set for Primary Focus, optional supporting ingredients,
  and canonical context. Selecting a tab is local presentation state and does not persist a MEC
  stage transition.
- The Quest objective remains in the Journey header, while requirements remain available in a
  secondary disclosure outside the Map learning panel.
- Explore concentrates on the practice focus, supporting skills, required techniques, and target
  tempo without duplicating stage introduction, requirements, or Session activity.
- Craft keeps its creative invitation, prompt ideas, truthful no-save/no-grade copy, ingredients,
  and boundaries without repeating the stage heading.
- The right-side Practice panel and all lifecycle, Session, evidence, and progression semantics are
  unchanged.

No migration, Supabase configuration change, production change, or public-traffic change is part
of UX-006-R2. The user accepted UX-006, UX-006-R1, and UX-006-R2 in the refreshed Preview on
2026-10-20 and explicitly authorized final closeout through the protected `v1-production` merge.
