# DIF-001 — Difficulty Model Contract

**Status:** COMPLETE  
**Date:** 2026-09-27  
**Authority:** Phase 0 — Architecture & Contracts

## Objective

Define multidimensional Quest demand and Player-relative difficulty without assigning inherent difficulty to canonical Skills.

## Result

Absolute Quest demand now uses seven dimensions:

1. Technique
2. Fretboard
3. Theory
4. Rhythm
5. Creative
6. Tempo
7. Constraint

Each applicable dimension uses an internal 0–100 score and visible Level I–V. Non-applicable dimensions remain null rather than being mislabeled Level I.

Personal difficulty is separate and uses:

- I — Very Comfortable
- II — Comfortable
- III — Target Challenge
- IV — Stretch
- V — Overreach

Personal evaluation status is:

- UNKNOWN
- PROVISIONAL
- RESOLVED

Critical invariants:

- Skills have no inherent fixed difficulty
- absolute Quest demand is Player-independent
- personal difficulty is a time-stamped Player × Quest evaluation
- an UNRATED Primary Skill cannot produce a resolved personal difficulty
- readiness can raise current challenge without lowering proficiency
- confidence controls uncertainty rather than capability
- context novelty is bounded and does not duplicate Skills
- XP and Character Level are not difficulty inputs
- verification mode does not change Quest demand
- difficulty does not directly define rewards

## Reference

DORIAN CROSSROADS is accepted as absolute demand III with:

- Technique III
- Fretboard III
- Theory II
- Rhythm III
- Creative N/A
- Tempo III
- Constraint III

Player-relative examples cover UNRATED, ESTIMATED, matched, stale/low-readiness, overqualified, novel-context, and supporting-skill-bottleneck states.
