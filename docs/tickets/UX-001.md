# UX-001 — Hybrid Design-System Contract

**Status:** COMPLETE  
**Date:** 2026-09-27  
**Authority:** Phase 0 — Architecture & Contracts

## Objective

Formalize GuitaRPG's approved hybrid visual language as a machine-readable, accessible, responsive design-system contract before product-screen implementation.

## Result

Three related surface modes are now canonical:

- Instrument HUD — Play / Generate / Training / Quest / Session
- Codex — learning / reference
- Practice Lab — Character / Skills / History / analytics

The ticket defines:

- owned color tokens
- semantic state colors
- typography roles
- spacing
- radii/borders
- responsive breakpoints
- 44 px minimum touch targets
- desktop/mobile navigation
- motion and reduced-motion behavior
- accessibility invariants
- core component inventory and required states

Core components:

- AppShell
- Sidebar
- MobileNav
- Panel
- QuestCard
- SkillBadge
- DifficultyBadge
- ProgressBar
- AttributeDisplay
- StatusChip
- MetricCard
- ActionButton

Color is never the sole state signal.

## Implementation seed

`app/design-tokens.css` now contains the CSS custom-property token implementation.

The FND-002 `--color-*` variables remain compatibility aliases to Instrument HUD tokens.

No product feature screens are implemented by this ticket.
