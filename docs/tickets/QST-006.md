## Objective

Establish the bounded persistence foundation for generated Quest drafts and Player-owned Quest Journeys while preserving immutable Quests, one-Session-per-attempt behavior, and Result-only progression authority.

## Scope delivered

- `QST_DRAFT_V1` same-tab `sessionStorage` envelope with a 24-hour expiry, auth UUID binding, canonical Quest parsing, and fail-closed cleanup.
- Explicit unsaved-draft replacement confirmation on Generate.
- Transactional/idempotent generated Quest + Journey persistence through `save_generated_quest_journey`.
- Distinct Save Quest (`SAVED`/`MAP`), Start Quest (`ACTIVE`/`MAP`, no Session), and Start Practice (`ACTIVE`, new Session) paths.
- One owner-scoped `player_quest_journeys` row per immutable Quest.
- Revisitable `MAP`, `EXPLORE`, and `CRAFT` stage persistence.
- Trusted `START`, `CONCLUDE`, `ABANDON`, `REOPEN`, `ARCHIVE`, and `UNARCHIVE` lifecycle operations.
- Reversible archive state through `archived_from_status`.
- Lazy overlay for legacy Quests: attempted Quests become `ACTIVE`/`EXPLORE`; unattempted Quests become `SAVED`/`MAP`.
- Minimal `/quest/[questId]` foundation route with objective, lifecycle, stage controls, suggested duration, and Start Practice.
- Existing Quick and Training start bridges now ensure a durable active Journey before invoking unchanged SES_V1 Session creation.

## Database contract

- Migration: `20261017000000_qst_006_quest_journey_persistence.sql`
- Ownership is derived from `auth.uid()` and checked against the referenced Quest owner by a private trigger.
- Authenticated clients have owner-scoped `SELECT` only; all mutations use explicitly granted SECURITY DEFINER RPCs with an empty search path.
- Quest creation/retry is serialized per Quest UUID with a transaction-scoped advisory lock.
- Exact immutable-snapshot retries return the existing Quest/Journey; conflicting content for the same UUID is rejected.
- Journey actions do not touch Sessions, Results, XP, Skill state, readiness, Attributes, recommendations, or History.

## Non-goals

No Saved Quest library, final MEC shell, Journal, fretboard, Codex Peek, Build Quest composer, Training redesign, bulk legacy backfill, or production environment change is included.
