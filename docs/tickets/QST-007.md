## Objective

Turn the durable QST-006 Quest Journey foundation into an owner-scoped, paginated Saved Quest collection while preserving the separation between actionable Journey work and Session-first History.

## Scope

- Dedicated `/quests` collection grouped as Active, Saved, Concluded, Stopped, and Archived.
- Deterministic 20-row pagination ordered by last worked, creation time, and Quest ID.
- Three-item actionable Recent Quests read model for Home.
- Owner-scoped lazy Journey creation for pre-MEC Quests through `ensure_player_quest_journeys()`.
- Immutable Quest, Journey, Session-count, latest-Session, and latest-Result summaries.
- Recent five-Session Quest detail activity with Continue Practice, Record Result, and View Details actions.
- Practice Again against the same immutable Quest ID through shared Journey lifecycle handling.
- Archive and prior-status Restore through QST-006 lifecycle RPCs.
- Desktop Play navigation and Generate discovery without changing the four-item mobile bottom navigation.

## Boundaries

History remains Session/Result based. Journey reads and lifecycle actions create no History record, Result, XP, proficiency, confidence, readiness, Attribute, or recommendation mutation. No final MEC shell, Codex Peek, Journal, fretboard, Build composer, Training redesign, DATA-005, or production change is included.
