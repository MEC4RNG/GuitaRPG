# PLY-001 — Player & Development State Contract

**Status:** COMPLETE  
**Date:** 2026-09-27  
**Authority:** Phase 0 — Architecture & Contracts

## Objective

Define the persistent state required to represent a guitarist and their development before Quest, evidence, and progression implementation begins.

## Result

The Player model now formally separates:

- player-authored profile/preferences
- Skill development state
- Character progression state
- historical evidence

Key states:

- Skill assessment: UNRATED / ESTIMATED / ESTABLISHED
- Skill Level: I–V
- readiness: UNKNOWN / LOW / MODERATE / HIGH
- Attributes: UNASSESSED / ESTIMATED / ESTABLISHED
- optional calibration
- multiple tuning preferences
- Character Level + Practice XP
- derived Character Attributes

Critical invariants:

- UNRATED is not Level I
- self-declared experience does not grant proficiency
- XP cannot promote Skill proficiency
- inactivity alone cannot lower historical proficiency
- readiness may decline independently
- Skills are not duplicated by tuning
- Concepts/Contexts/Constraints do not receive direct player proficiency
- derived progression values are system-authoritative under DATA-001
