# EVD-002 — Result / Completion / Reflection

**Status:** IN PROGRESS
**Phase:** 2 — Core Quest Loop
**Depends on:** EVD-001, QST-002, SES-001, SES-002, DATA-001, PROG-001

## Objective

Implement the EVD_V1 workflow that atomically finalizes exactly one durable Result for
one ended Practice Session, derives meaningful attempt and criterion outcomes from the
immutable Quest plus trusted Session facts and permitted SELF observations, and records
optional Player reflection and notes.

## Authority and boundaries

EVD-001 defines the canonical outcomes, criterion states, verification modes,
confidence values, source authorities, reflection values, and outcome derivation.
QST-002 supplies the immutable Quest completion contract and structured Objective.
SES-001 supplies authoritative lifecycle history and active time. SES-002 supplies
append-only BPM and repetition telemetry. DATA-001 controls ownership, RLS, trusted
mutation, and account deletion. PROG-001 consumes Results later but is not implemented
here.

EVD-002 does not award XP, update Character Level, proficiency, confidence, readiness,
or Attributes, select recommendations, implement History, create audio/app analyzers,
claim mastery, or authorize production cutover.

## Accepted semantic plan

- `EVD_V1` has exactly ABANDONED, ATTEMPTED, PARTIAL, and CLEARED outcomes.
- Meaningful attempt uses the Quest's accepted `MEANINGFUL_ACTIVITY` contract and
  numeric `minimum_attempt_seconds`, compared with SES-001 recorded active seconds.
- System-observable metrics are an explicit registry. EVD-002 supports authoritative
  duration (`practice_duration`, `time_elapsed`) and the latest persisted metronome
  configuration (`target_tempo`). It never treats metronome configuration as proof of
  musical accuracy or rep telemetry as clean/correct repetitions.
- Ordinary Player submissions may create only PLAYER/SELF evidence. Trusted logic
  assigns MODERATE confidence and derives MET/NOT_MET from scalar EQ/GTE/LTE comparison;
  explicit uncertainty produces UNKNOWN.
- ABANDONED makes every required Objective criterion NOT_EVALUATED and may retain
  SESSION/HIGH `practice_presence` supporting evidence.
- Finalized Result, criterion, and evidence rows are immutable to ordinary clients.
  Audited corrections remain deferred.
