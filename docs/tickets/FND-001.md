# FND-001 — Production Architecture Decision

**Status:** COMPLETE  
**Date:** 2026-09-27  
**Authority:** Phase 0 — Architecture & Contracts

## Objective

Select and document the production architecture for GuitaRPG before feature implementation begins.

## Result

Accepted architecture:

- Next.js App Router + React + TypeScript
- Vercel deployment
- Supabase PostgreSQL + Auth
- PostgreSQL Row Level Security for player-owned data
- Tailwind CSS + GuitaRPG design tokens
- runtime schema validation at trust boundaries
- browser-first optional audio architecture using Web Audio / media-input APIs
- unit + integration + database security + Playwright E2E testing

## Repository disposition

The existing static GitHub Pages site remains on `main` as the legacy/live reference until an explicit later cutover.

A new `v1-production` branch has been created from the current `main` head for production application development.

No legacy production file was modified by this ticket.
